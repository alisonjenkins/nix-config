# HUTUBS anthropometry data

`hutubs_anthropometry.json` is a machine-readable conversion of
`AntrhopometricMeasures.csv`, from:

Brinkmann, F., Dinakaran, M., Pelzer, R., Grosche, P., Voss, D., and
Weinzierl, S., "A Cross-Evaluated Database of Measured and Simulated HRTFs
and Headphone Impulse Responses" (the HUTUBS HRTF database), TU Berlin,
2019. https://doi.org/10.14279/depositonce-8487

Licensed CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).
Downloaded from
https://depositonce.tu-berlin.de/items/dc2a3076-a291-417e-97f0-7697e332c960
(the "Antrhopometric measures.zip" file — misspelling as-shipped) on
2026-09-14.

`d1`-`d10` are pinna distances in cm, `theta1`/`theta2` pinna angles in
degrees, both per ear (left/right), following the same measurement
definitions Algazi/Duda/Thompson/Avendano defined for the CIPIC database
(d1-d8 identical; HUTUBS adds d9 = cavum concha depth (back), d10 = crus of
helix depth). See `AntrhopometricMeasures.pdf` in the same source archive
for the full parameter list and diagram.
