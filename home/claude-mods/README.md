# Claude Code mods

One directory per mod (a Claude Code plugin of function hooks: panes, status
line, toasts, tool-call hooks). Auto-discovered by `flake.lib.mods` and loaded
into every session through `programs.claude-code.plugins`. Adding a directory
is the whole registration step.

Authoring workflow, layout and checks: the `claude-code-mods` skill
(`.claude/skills/claude-code-mods/SKILL.md`).
