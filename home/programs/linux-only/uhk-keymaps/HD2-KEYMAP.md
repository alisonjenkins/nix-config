# Helldivers 2 stratagem keymap (HD2)

Generated by `hd2-keymap.nix` from `stratagems.nix`. This doc is the
human-readable index into that data; edit `stratagems.nix`, not this file,
and regenerate the tables below if the mapping changes.

## Layer access

The thumb cluster has four dedicated keys: `Fn`, `Mod`, `Space`, `Fn2`. Fn3,
Fn4 and Fn5 don't get their own physical key — they're reached by holding one
of three otherwise-idle keys straight from the base layer, the same way Fn
and Fn2 are:

| Hold | Base-layer key | Goes to |
|---|---|---|
| Fn | thumb cluster | `fn` |
| Fn2 | thumb cluster | `fn2` |
| Fn3 | grave / backtick (left of `1`) | `fn3` |
| Fn4 | left Ctrl (left of `A`) | `fn4` |
| Fn5 | ISO key (left of `Z`) | `fn5` |

First attempt chorded Fn3/4/5 through the Fn layer (hold Fn, then hold a
second key) — too fiddly under game pressure to hit reliably. Remapped to
these three single dedicated hold-keys instead, confirmed against the real
device.

## Stratagem placement

Direction codes are U/D/L/R (up/down/left/right), read left-to-right as the
game shows them; the key each direction presses is set once in
`constants.nix` (`directionKey`, currently WASD). Each key plays a macro that
holds Ctrl, then presses each direction with a hold + gap between (a plain tap
was too brief for the game to register reliably).

## Generation and push

`programs.uhkKeymaps.enable` (see `default.nix`) writes the full
`UserConfiguration.json` — this keymap plus the daily-driver ones, with
sops-decrypted secret macro text substituted in — to
`~/.local/state/uhk/UserConfiguration.json` at home-manager activation time.
Nothing pushes it to the physical keyboard automatically yet: import it in
UHK Agent from that path and save to device.
